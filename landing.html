Alberta Energy BI Agent

Ask questions about Alberta oil and gas data in plain English. The agent writes the SQL, checks it for safety, runs it, and shows you the table, chart and query.

Open the live demo Source code

The demo is hosted on a free tier and goes to sleep when nobody has used it for a while. If you see a "this app has gone to sleep" page, click Yes, get this app back up! and wait for it to start. The demo runs on synthetic data (fictional operators, simulated volumes) shaped like Alberta Energy Regulator and Petrinex reporting.

How it works

Data dictionaryA YAML semantic layer defines tables, units (m³, e³m³), metrics such as GOR and water cut, and example queries.
Two-layer safetySQL is parsed and restricted to a single SELECT on known tables. The database is read-only with file access disabled.
Self-repairIf a query fails, the error goes back to the model for up to two fixes.
Admin consoleQuery log, token usage, thumbs up/down feedback, schema drift check and benchmark results.

Built with

  • DuckDB, sqlglot, Streamlit, Python
  • LLM access through free-tier APIs or a local model (Gemini, Groq, Ollama), with Claude as an option
  • A 26-question benchmark that scores execution accuracy against reference SQL, reported per model in the repo
